# common — knowledge index

**Ships empty.** Lines are appended as files are added.

## Line format

```text
- [<file>](<file>) — <one line saying what it is for>
```

## Scope

Knowledge here is read by **every** role, so it holds only what is true regardless of which baton is
running — shell and platform traps, measurement discipline, verification recipes. Anything that only
one role acts on belongs in that role's own directory instead.
